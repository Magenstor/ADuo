# 052 — Renombrar y borrar lista

| | |
|---|---|
| **Estado** | hecha |
| **Bloque** | Frontend · Interfaz |
| **Depende de** | [049](049-ui-listas.md) |
| **Bloquea a** | — |

## Objetivo

Gestionar las listas.

## Pasos

- [x] Renombrar cualquier lista del hogar.
- [x] Borrar lista con confirmación que dice **cuántos artículos se pierden**.

## Hecho cuando

- Borrar la lista borra sus artículos en todos los dispositivos.

## Ojo con esto

La confirmación tiene que decir el número de artículos. "¿Seguro?" no informa de nada; "se perderán 14 artículos" sí.
