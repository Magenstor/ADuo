# 051 — Renombrar y borrar lista

| | |
|---|---|
| **Estado** | pendiente |
| **Bloque** | Frontend · Interfaz |
| **Depende de** | [048](048-ui-listas.md) |
| **Bloquea a** | — |

## Objetivo

Gestionar las listas.

## Pasos

- [ ] Renombrar cualquier lista del hogar.
- [ ] Borrar lista con confirmación que dice **cuántos artículos se pierden**.

## Hecho cuando

- Borrar la lista borra sus artículos en todos los dispositivos.

## Ojo con esto

La confirmación tiene que decir el número de artículos. "¿Seguro?" no informa de nada; "se perderán 14 artículos" sí.
