# 054 — Estados vacíos

| | |
|---|---|
| **Estado** | pendiente |
| **Bloque** | Frontend · Interfaz |
| **Depende de** | [048](048-ui-listas.md) |
| **Bloquea a** | — |

## Objetivo

Que la aplicación nunca parezca rota.

## Pasos

- [ ] Estado vacío cuando no hay ninguna lista, que invita a crear una.
- [ ] Estado de la interfaz cuando el segundo miembro todavía no está dado de alta.

## Hecho cuando

- Borrar la última lista muestra un estado vacío, no una pantalla en blanco.

## Ojo con esto

Se puede borrar la última lista. No se inventa una regla de "mínimo una lista": se resuelve mostrando algo útil.
